# Сцены OBS «Двор»

Локальные страницы для OBS: браузерный источник → «Локальный файл», 2560×1440, 30 FPS, не выгружать при скрытии.

- `start-scene/index.html` — перед стримом. Вечер, табло «СКОРО НАЧНЁМ» с отсчётом.
- `end-scene/index.html` — конец стрима. Ночь: зрители прощаются и расходятся по подъездам, окна гаснут, последней уходит бабушка. Лучшие в чате выходят на поклон. На табло — «СПАСИБО ЗА СТРИМ», титры эфира (топ чата, новые фолловеры, сабы, донатеры — только имена) и анонс.
- `webcam-scene/` — большая вебка, чат слева на «Доске почёта» (сторона — `BOARD.x` в `wall.js`). Три слоя: `wall.html` (стена хрущёвки и «Доска почёта» под чат) → вложенная сцена «Камера в окне» (камера + `frame.html`, пиксельная рама с подоконником, кактусом, кружкой, радио и котом) → `yard.html` (полоска двора внизу, зрители толпятся под окном). Камеру двигай/масштабируй элементом «Камера в окне» — рама едет вместе с ней. Под заголовком «Доски почёта» — таблички «ДЕНЬ» и «МЕСЯЦ»: лучший донатер по сумме за сегодня и за месяц (по местному времени бота, доллары пересчитываются по курсу ЦБ, тестовые и запланированные донаты не считаются). Стена спрашивает бота (прод, запасной — локальный) раз в 30 секунд (`donations:top`), длинные имена прокручиваются, новый лидер мигает, пока донатов нет — «ЖДЁТ ГЕРОЯ». Превью: `wall.html#demo`. Реплики над головами здесь выключены (`bubbles: false` в `config.js`), потому что чат и так виден рядом.
- `donors/index.html` — топ донатеров отдельным источником (960×112): «ДОНАТЕР ДНЯ» и «ДОНАТЕР МЕСЯЦА» шрифтом табло, с тёмной обводкой, без рамки. Строка видна, только когда есть донаты; нет донатов — источник пустой. Подходит для любой сцены: выравнивание (`align`), размер пикселя (`scale`), подписи и длина имени — в `donors/config.js`. Стоит на «Старт» и «Конец стрима» над табло. Превью: `index.html#demo`.
- `alerts/index.html` — алерты донатов со всех сервисов одним источником на весь экран (2560×1440; сам алерт — на месте алерт-бокса SE, `box` в `config.js`). На каждый донат сверху падают пиксельные деньги: чем больше сумма, тем гуще — копейки, рубли, с 300 ₽ купюры, с 5000 ₽ золотой ливень (`coins: false` — выключить). Бот сам слушает DonationAlerts, StreamElements, DonatePay и Donatex, ставит донаты в одну очередь и присылает их сюда. Вид алерта и вариации по суммам берутся из алерта на донаты в оверлее StreamElements (правь там, как раньше), озвучка — родная у каждого сервиса: голос и нейроголос из DA, голоса Donatex и ответ их ИИ-ассистента (бот ждёт его файл до 40 секунд; отдельный виджет «ИИ-ассистент» Donatex в OBS не нужен — иначе ответ прозвучит дважды), голоса DonatePay, голос SE для донатов через SE. Платные «плюшки» доната DonatePay тоже показываются, как в их виджете: картинка/гифка донатера — на весь экран на 5 секунд перед алертом или вместо картинки алерта (как выбрано в настройках DonatePay), эффект (сердечки, звёзды, конфетти, пузыри, Kappa, 4Head) — поверх алерта (`premium.js`). Видео вариаций качаются заранее. Включается в админке → «Алерты»; там же ссылка на док для OBS (статусы сервисов, выключить/перезапустить сервис, пауза, пропуск, повтор, тест). Превью без бота: `index.html#demo`, с плюшками DonatePay — `#demo&fx=HeartUp&pic=<ссылка на картинку>`.
- `shared/` — общий движок: двор, персонажи, табло, стили, шрифт.
- `windows/` — перенос всего этого в OBS на Windows (см. ниже).

## Горячие клавиши

Работают, даже когда OBS не в фокусе (NumLock должен быть включён).

| Клавиши | Что делает |
|---|---|
| Alt+Num0 | сцена «Большая вебка» |
| Alt+Num1 | «Main monitor» — шаринг экрана |
| Alt+Num5 | «Видосики» |
| Alt+Num3 / Alt+Num4 | «Старт» / «Конец стрима» |
| Alt+Num7 | вебка крупно по центру в раме окна; маленькая вебка на сцене прячется. Ещё раз — обратно |
| Alt+Num8 | размыть захват экрана / убрать размытие (в «Main monitor» и «Видосиках») |

Крупная вебка — элемент «Камера в окне» в каждой сцене (кроме «Большой вебки» и «Chat and Webcam», там она и так большая). Alt+Num7 переключает видимость крупной и маленькой вебки разом. Если руками скрыть одну из них, они поменяются местами «не в ту сторону» — верни как было глазиком.

Размытие — сцена «Экран · размытие»: тот же захват экрана, сжатый фильтрами «Масштабирование» до 64×36 и растянутый обратно (плагины не нужны). Сильнее или слабее — поменяй разрешение в фильтре «Размытие · сжать».

## Windows

OBS на Windows берёт те же страницы с диска `D:` (Linux `/media/nglzzz/projects` = `D:`, `storage` = `E:`, `hdd` = `F:`, `games` = `G:`), поэтому правки в `obs/` видны сразу в обеих системах. Сцены переносятся отдельным профилем и коллекцией `nglzzz-dvor`, старые остаются.

1. На Linux: `python3 obs/windows/build.py` — берёт текущую коллекцию сцен Linux, меняет пути на буквы Windows, подставляет устройства Windows (вебка C920 в 1080p, DroidCam, захват монитора, микрофоны с фильтрами, петличка) и складывает в `obs/windows/out/` (в git не попадает — там токены виджетов).
2. На Windows: закрыть OBS, запустить `D:\www\twitch-bot\obs\windows\install.cmd`. Скрипт делает копию настроек в `%APPDATA%\obs-studio\backup-<дата>`, кладёт коллекцию, создаёт профиль `nglzzz-dvor` копией профиля `nglzzz` (ключ стрима, NVENC, выход 1080p60) и добавляет доки (Music, Donations, Twitch Chat и др.).
3. Вернуться к старому: Профиль → `nglzzz`, Коллекция сцен → `nglzzz`.

После изменений сцен на Linux повтори оба шага — коллекция `nglzzz-dvor` на Windows заменится свежей.

Зрители из чата Twitch (список chatters от бота + все, кто пишет) гуляют во дворе персонажами. Костюм выбирается по нику. Сообщения чата появляются репликами над головой. Сами по себе случаются драки, обнимашки, толчки, поездки на машине, хедкраб из люка, «ФУС-РО-ДА», закладка бомбы на «A».

Донат (в момент его алерта) празднует весь двор: жители прыгают и машут руками, из-за краёв прибегают ещё (чем больше донат, тем больше), летят монетки; с 300 ₽ — салют над домом, с 1000 ₽ — дискотека в окнах. Превью: `index.html#demo&quiet&donate=1000`.

Команды чата разыгрываются на сцене: `!обнять`, `!шлёп`, `!убить`, `!кусь`, `!тьфу`, `!секс` (поцелуй).

- Данные (зрители, чат, итоги, донаты) идут от бота по websocket: сначала прод `wss://nglzzz.xyz/ws`, если он не отвечает — локальный `ws://localhost:86` (список в `config.js`, логика в `shared/js/socket.js`). Сами страницы локальные и рисуются сразу; связь держится постоянно и восстанавливается сама.
- Настройки — `config.js` каждой сцены: адрес websocket бота, тексты табло, отсчёт/время разъезда, лимит людей, снег.
- Когда сцену показывают в OBS, отсчёт и финал начинаются заново.
- Превью в браузере без бота: `index.html#demo`. Конкретные события: `#demo&events=fight,car,fus,bomb,crab,hug,kiss,shove`. Для финала: `#demo&quiet&close=1` — без сообщений, двор пустеет за минуту.
- Чат в сцены не встроен — это сторонний источник поверх (место под него — небо над гаражами справа сверху). В трёх сценах лежат «Чат · RTE» (основной) и «Чат · ChatIS» (запасной, скрыт): если RTE не работает — выключи его и включи ChatIS.
- `chat/chat-skin.css` — общий скин обоих чатов (сообщения бумажными записками, как реплики над головами). Его текст вставлен в «Пользовательский CSS» обоих источников; после правки файла вставь заново. В OBS не работают `@import` и CSS-переменные — шрифт подключён через `@font-face`, значения записаны прямо.
- Шрифт Pixelify Sans (OFL, `shared/fonts/OFL.txt`).
